📥 Choose the right source mode

Public

Registry

Approved public sources. Browse reviewed ElectionPulse registry entries.

Selecting a source does not grant execution authority.

Trusted

Upload

Local election artifact. Use trusted upload controls for an allowed local file.

Trusted

URL Library

Approved trusted targets. Choose from the governed URL library.

Ballot Lens does not turn arbitrary pasted URLs into execution authority.

Trusted

Worklist

Governed queue handoff. Start from an authorized Worklist selection.

Worklist selection does not bypass target validation.

Why is “Run approved source” disabled?

The selected registry source must exactly match the server-provided execution-eligible source for the current envelope. Approval metadata alone does not enable a run.

🔐 Sessions and ownership

Active session
The server creates the active session for a run. The browser does not invent or rebind session authority.
Selection lock
Source selection stays locked while an active run owns the workspace.
Foreign or stale events
Events outside the active server-owned session are rejected rather than merged.
Session History
Session History is view-only. Inspecting an older session does not resume it, rebind parser authority, or replace the active session.

🛎️ Action Required

Action Required is server-authored.

Some runs need a contest choice, vote-method choice, challenge response, or another bounded input. Respond only for the active session.

📊 Results & Validation

Canonical comparison
Comparison is EXACT_MATCH or UNRESOLVED. UNRESOLVED is not automatically a mismatch.
Unknown values
Unknown or unavailable values stay distinct from numeric zero.
Diagnostics
Inspect connection, provider, checkpoint, output, and terminal state without changing parser authority.

🛠️ Troubleshooting

Trusted modes are locked

Trusted controls require the trusted principal/certificate path.

The run button is disabled

Confirm the selected source is the exact source currently authorized for execution.

A historical session will not resume

Expected: Session History is inspect-only and does not restore or rebind parser sessions.

Canonical comparison says UNRESOLVED

UNRESOLVED is not a mismatch claim.

Security boundary:

Browsing, selecting, or inspecting a source does not create new execution authority.
