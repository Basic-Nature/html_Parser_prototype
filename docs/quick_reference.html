🔗 Direct URL Processing NEW

How to Use:

  • Select "Direct URLs" radio button in Controls
  • Paste URLs in textarea (one per line)
  • Maximum 20 URLs per batch
  • Real-time validation with color-coded feedback
  • Enable "Batch Mode" for automatic contest processing
💡 Tip: Direct URL drafts are saved per session. Switch sessions to work on different URL sets without losing your work!

URL Validation Rules:

  • Only http:// and https:// protocols allowed
  • URLs with usernames/passwords are rejected (security)
  • Invalid URLs are highlighted in red
  • Valid URLs show green checkmark with count
⚠️ Warning: URLs exceeding the 20-item limit will be truncated. Split large batches into multiple sessions.

💾 Filter Presets NEW

Save Your Favorite Filters:

  • Adjust Confidence, State, and Log Level filters
  • Click "Save" button
  • Enter a descriptive name
  • Preset appears in dropdown
  • Select preset to instantly restore filters
  • Delete unwanted presets anytime
💡 Tip: Create presets for common workflows like "High-Confidence Only" (90%+, All states, ERROR only) or "California Full" (0%+, CA, INFO).

🔄 Session Management NEW

Clone Session:

Creates an exact copy of your current session including all settings, filters, and URL drafts. Perfect for testing different configurations side-by-side.

Export Data:

Downloads all session results as a JSON file with timestamp. Useful for archiving, sharing, or post-processing in external tools.

Clear Logs:

Removes all log entries for the current session. Helpful when starting a new parse run or debugging specific issues.

📚 Common Workflows

Scenario 1: Process Multiple URLs Automatically

  1. Select "Direct URLs" radio button
  2. Paste 5-10 election results URLs
  3. Check "Batch Mode" checkbox
  4. Click "Run Parser"
  5. Parser processes all URLs and contests without prompts

Scenario 2: Filter and Export High-Quality Results

  1. Set Confidence slider to 85%+
  2. Select specific State from dropdown
  3. Set Log Level to "Errors" only
  4. Click "Save" in Filter Presets → name "High Quality"
  5. Click "Export Data" to download JSON

Scenario 3: Compare Different Processing Settings

  1. Run parser with normal settings
  2. Click "Clone Session" (Ctrl+Shift+C)
  3. Switch to cloned session in sidebar
  4. Change settings (e.g., enable Output Bypass)
  5. Run parser again and compare results

🛠️ Troubleshooting

Direct URLs not validating?
  • Ensure URLs start with http:// or https://
  • Remove any trailing spaces or special characters
  • Check that URLs don't contain @ symbols (credentials)
  • Verify total count doesn't exceed 20
Filter presets not saving?
  • Check browser localStorage is enabled
  • Try a different preset name (avoid special characters)
  • Refresh page and try again
Keyboard shortcuts not working?
  • Ensure no modal is open (press Escape first)
  • Check that no input field has focus
  • Try refreshing the page
