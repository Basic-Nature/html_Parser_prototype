📍 Main Content Areas

🔗 Left Sidebar: URLs & Files

Purpose: Manage data sources
Contains: URL library, upload manager, run overview
Actions: Toggle sources, track session info

📊 Results Preview Bar

Status: Collapsible bar at top
Shows: Pipeline progress (PREPARE → SOURCE → RUN → REVIEW)
Actions: Search results, refresh, expand/collapse

🎯 Results Grid

Content: Contest cards with parsed data
Shows: Ballot measure, contests, results
Actions: Click cards to preview, export individual contests

⚙️ Right Sidebar

Location: Collapsible tools panel (right edge)
Contains: Export options, settings, advanced controls
Access: Click ⚙️ button in navbar

📡 Source Carousel

Where: Left sidebar under "URLs & Files"
Options: URL Library, Manual Uploads
Use: Switch between data sources (swipe or dot click)

🔍 Search & Filter

Location: Results preview bar
Action: Type to filter contests by name/state/type
Result: Real-time filtering of grid below

🎯 How To...

Switch Between URL Source & Uploads

  1. Look at Left Sidebar → URLs & Files
  2. Click the dot indicators or swipe carousel cards
  3. Current source highlighted (active dot)
  4. Available URLs or upload list appears in carousel

View Parsed Results

  1. After parser run completes, Results Preview Bar opens
  2. View pipeline stages: PREPARE → SOURCE → RUN → REVIEW
  3. Results Grid shows contest cards below
  4. Click any card to expand/preview details
  5. Scroll to see all contests

Search Results

  1. Open Results Preview Bar if collapsed (click header)
  2. Find search box: 🔍 Search results...
  3. Type contest name, state, or ballot type
  4. Grid updates in real-time to show matches
  5. Clear search to reset grid

Refresh Results

  1. In Results Preview Bar, click 🔄 Refresh
  2. Grid reloads latest parsed data
  3. Use if data seems stale or after editing source

Check Pipeline Status

  1. View Results Preview Bar progress track
  2. Stages: PREPARE (setup) → SOURCE (load data) → RUN (parse) → REVIEW (validate)
  3. Current stage highlighted; click to expand details
  4. Check Pipeline Hints bar below for messages

Export Data

  1. Click right-sidebar toggle: ⚙️ in navbar
  2. Navigate to Export section
  3. Choose format: CSV, JSON, or filtered view
  4. Select contests to include (or export all)
  5. Click Download

💡 Navigation Tips

  • Collapse/expand sections: Click section headers to toggle content visibility
  • Sticky navbar: Navigation bar stays at top while scrolling results
  • Live stage updates: Pipeline stages update in real-time as parsing progresses
  • Touch-friendly carousel: Swipe left/right on mobile to switch URL/upload sources
  • Search persistence: Search results filter grid dynamically (no page reload)
  • Keyboard accessible: Use Tab to navigate, Enter/Space to activate buttons
  • Modal focus trap: When modal opens, focus stays within the modal until closed (Escape or close button)
  • Empty state: If no results show, check pipeline status and refresh
  • Responsive sidebar: Left/right sidebars auto-collapse on mobile for more space
  • Hint messages: Watch pipeline hint bar below main content for helpful guidance

📊 Understanding Pipeline Status

Pipeline Stages:

  • PREPARE — Setting up session, validating inputs
  • SOURCE — Loading URLs or uploaded files
  • RUN — Active parsing of election data
  • REVIEW — Quality validation and results finalization

Current stage highlights; click stage to see details. Progress shown via visual indicators.
