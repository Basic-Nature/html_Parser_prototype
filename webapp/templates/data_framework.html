Authority + Provenance Guide

A persistent reminder of the semantic rules that govern every Data Framework view.

Governed semantics
NULL is evidence.Unknown, unavailable, or unreported values stay NULL; they are never display-coerced to zero.
Scope stays precise.Jurisdiction type and name remain explicit; district, county, and precinct are not interchangeable.
Staging is not canonical.Review and publication state must remain visible rather than inferred from where a row happens to appear.
Provenance travels with data.Source labels, evidence links, and reported-versus-derived meaning remain distinguishable.
